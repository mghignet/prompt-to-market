# Instructions pour les agents

## Memlog

[`.memlog.md`](.memlog.md) garde les idées et décisions prises en session, pour les retrouver d'une session à l'autre.

- Quand une PR vient d'être ouverte, et pas avant, propose de mettre à jour `.memlog.md`. Attends l'accord.
- Ajoute alors une entrée en haut du fichier, titrée par la date et la PR. Garde ce qui sert la présentation : le contexte, les décisions, les idées écartées avec leur raison et les points ouverts.
- N'y recopie pas ce que le code ou git disent déjà.
